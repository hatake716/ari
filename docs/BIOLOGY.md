# 生態モデルと設計上の仮定

ARIは温帯の地中営巣性のアリを参考にした放置観察ゲームです。特定種の個体群を実測データにフィットした研究用モデルではありません。以下では、資料で確認した生態と、ゲームのために置いた係数を分けます。資料は2026年9月17日に確認しました。

## 生態として参考にしたこと

1. 創設・働きアリの増加・繁殖個体の生産という群れのライフサイクル。創設女王は最初の子の世話をし、働きアリが育つと採餌や育児などを任せます。成熟した群れが子女王と雄を生産するまでには通常数年を要します。
   - [Arizona State University / Life Cycle of an Ant Colony](https://askabiologist.asu.edu/ant-colony-life-cycle)
2. 女王による産卵、完全変態（卵・幼虫・蛹・成虫）、働きアリによる採餌と巣の掘削、成熟後の有翅個体の結婚飛行。Camponotusの多くは木に営巣しますが地中に営巣する種もあり、糖分と昆虫由来の栄養を利用します。
   - [National Park Service / Carpenter Ant](https://www.nps.gov/articles/carpenter-ant.htm)
3. 温度による発育条件の差と、育児個体の移動。論文はCamponotus musの温度選好と育児個体の配置を扱っています。以下の正弦波・発育係数・日数をこの論文から得たものとは主張しません。
   - Roces F, Núñez JA. 1989. *Brood translocation and circadian variation of temperature preference in the ant Camponotus mus*. Oecologia 81:33–37. [DOI](https://doi.org/10.1007/BF00377006) / [PubMed](https://pubmed.ncbi.nlm.nih.gov/28312153/)

創設女王はすでに交尾を終えて入巣した個体を想定します。母女王が子女王と必ず交代する仕組みは実装しません。子女王が新しい巣へ旅立つ「世代継承」をクリアとして扱い、母女王は元の巣に残ります。これは子女王による母女王の捕食・死亡・置換とは異なります。

## ゲーム用の時間・生理係数

すべてこのゲームの設計値であり、種を特定した実測値ではありません。

| 項目 | 設定と意味 |
|---|---|
| 時計 | 1倍では現実の1秒＝ゲームの1秒。内部積分は30分刻み、端数を保存 |
| 開始季節 | 年内120日目付近（暖かい時期） |
| 季節温度 | `T = 17 + 10 sin(2π (yearDay − 80) / 365)` ℃ |
| 活動・発育係数 | `a = clamp((T − 7) / 18, 0.12, 1)` |
| 冬 | `T < 12℃`。産卵と新たな襲撃が止まり、既存の幼虫などはゆっくり成長 |
| 働きアリの発育 | 基準18日（卵）＋22日（幼虫）＋20日（蛹）。実時間は活動係数・栄養で変化 |
| 働きアリの寿命 | 羽化から420日 |
| 女王の産卵率 | `min(0.42 + 0.048 W, 32) × a` 個/日。栄養不足・冬には抑制 |
| 子女王の発育 | 基準80日。性・カースト決定や雄の発育は集約モデル |
| 成熟による繁殖 | 創設1095日以上、働きアリ80匹以上、食料25超 |
| 過密による繁殖 | 創設365日以上かつ全個体数が収容目安の155%超。上記の働きアリ・食料条件も必要 |
| 旅立ち | 羽化から12日以上、気温19℃以上、外敵不在。移動・飛行の観察後にクリア |

過密だけで子女王の生産が必ず決まるという一般的な生態法則ではありません。これはユーザー指定の遊びを表現する独自ルールです。創設直後の大量増殖、女王が直接成虫を生む表現は避け、必ず発育段階を通します。

## 食料と役割

`W` は働きアリ数です。通常は約32%が採餌、18%が掘削、14%が警戒、残りが育児や維持を担います。侵入中は約65%を防衛へ動員し、採餌は12%、掘削は5%になります。役割は集約的に切り替わり、個別の年齢による職業分化はモデル化していません。

食料単位は糖・タンパク源を合算したゲーム単位です。採餌の収入は `0.19 × 採餌数 × a × 移動効率 / 日`、維持費は女王・働きアリ・幼体・子女王ごとの係数を合算します。初期の貯蔵と女王の体内資源で創設期を越えます。食料不足では発育が1/4に落ち、働きアリの死亡と女王の衰弱が進みます。食料の上限は巣の収容目安の2.5倍です。

## 巣と障害物

部屋と通路は連結グラフです。樹形・縦穴・広間の3種類から選び、広さを3段階で設定できます。プレイヤーは部屋の追加、女王室の指定、障害物の設置と削除ができます。部屋は最大20、障害物は最大8です。開始後は編集できません。

| 障害物 | 設置区間での働きアリの速度 | 設置区間での外敵の速度 |
|---|---:|---:|
| 小枝 | 64% | 30% |
| 小石 | 44% | 18% |

障害物は指定した通路の位置±11%だけに作用します。逆向きの移動でも同じ物理位置になります。経路探索は通過時間を考慮したDijkstra法です。採餌の効率と防衛への集合時間にも同じ通過時間を使います。別の枝に置いた障害物が女王室までの侵入経路を無条件に遅くすることはありません。

人口が収容目安の65%に達すると、働きアリが活動量に応じて部屋を広げ、その後に新しい部屋を掘ります。拡張中の部屋は徐々に掘られて画面に表れます。画面の外へ無限に拡張するモデルではなく、最大20室の観察範囲内で成長します。

## 侵入と戦闘

外敵はハネカクシ、ハサミムシ、オサムシをモチーフにしています。すべての種・個体が定期的に女王室を襲うという主張ではなく、捕食・防衛を観察するためのゲーム内イベントです。

初回は155日目以降、冬を除いて侵入します。撃退後は65〜150日後に次の襲撃が予定されます。種類・HPは経過年数で変化し、働きアリ数に合わせて自動的に同じ難度にする仕組みではありません。防衛数と集合時間からダメージを計算し、外敵が女王室へ到達したら巣の破壊と女王の捕食で終了します。障害物の飛び越しを防ぐため、外敵の移動を空間的に分割しています。

## 観察のための表現

- 生物学的な時間と、画面で読み取れる歩行アニメーションを分けています。早送りでも移動の向き・採餌・育児・掘削・防衛・局所的な障害物は反映しますが、1秒間に数日分の歩数は描きません。
- 大きな群れは最大110匹の働きアリで代表表示します。正確な群れの数は上部の数値です。
- 入巣・襲撃・旅立ちは一時的に最大1時間/秒へ減速し、発生直後の状態を飛ばさないようにします。
- 栄養、湿度、病気、遺伝、フェロモン拡散、3次元の通路、個体同士の衝突は簡略化または省略しています。
- 本作の成長日数は現実の単位で進みますが、厳密な現実の特定種の成長時期を保証するモデルではありません。
