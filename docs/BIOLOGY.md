# 生態モデルと設計上の仮定

ARIは温帯の地中営巣性のアリを参考にした放置観察ゲームです。特定種の個体群を実測データにフィットした研究用モデルではありません。以下では、資料で確認した生態と、ゲームのために置いた係数を分けます。資料は2026年9月17〜18日に確認しました。

## 生態として参考にしたこと

1. 創設・働きアリの増加・繁殖個体の生産という群れのライフサイクル。創設女王は最初の子の世話をし、働きアリが育つと採餌や育児などを任せます。成熟した群れが子女王と雄を生産するまでには通常数年を要します。
   - [Arizona State University / Life Cycle of an Ant Colony](https://askabiologist.asu.edu/ant-colony-life-cycle)
2. 女王による産卵、完全変態（卵・幼虫・蛹・成虫）、働きアリによる採餌と巣の掘削、成熟後の有翅個体の結婚飛行。Camponotusの多くは木に営巣しますが地中に営巣する種もあり、糖分と昆虫由来の栄養を利用します。
   - [National Park Service / Carpenter Ant](https://www.nps.gov/articles/carpenter-ant.htm)
3. 温度による発育条件の差と、育児個体の移動。論文はCamponotus musの温度選好と育児個体の配置を扱っています。以下の正弦波・発育係数・日数をこの論文から得たものとは主張しません。
   - Roces F, Núñez JA. 1989. *Brood translocation and circadian variation of temperature preference in the ant Camponotus mus*. Oecologia 81:33–37. [DOI](https://doi.org/10.1007/BF00377006) / [PubMed](https://pubmed.ncbi.nlm.nih.gov/28312153/)

4. クロオオアリの女王の長寿と、成熟した巣から季節ごとに有翅個体が旅立つこと。
   - [横浜市衛生研究所 / 「羽アリ」と「アリの結婚飛行」](https://www.city.yokohama.lg.jp/kenko-iryo-fukushi/kenko-iryo/eiken/geppo/2011/1104.files/110401.pdf)（2011年、3ページ）。クロオオアリの女王が10〜20年にわたって産卵すること、結婚飛行の時期を解説しています。文章・写真の転載は行っていません。

創設女王はすでに交尾を終えて入巣した個体を想定します。母女王が子女王と必ず交代する仕組みは実装しません。子女王が新しい巣へ旅立つ「世代継承」をクリアとして扱い、母女王は元の巣に残ります。1.3.0ではクリア後に同じ母女王の観察を続けられます。次の子女王が旅立つたびに再び選択を待ちます。これは子女王による母女王の捕食・死亡・置換とは異なります。

## ゲーム用の時間・生理係数

すべてこのゲームの設計値であり、種を特定した実測値ではありません。

| 項目 | 設定と意味 |
|---|---|
| 時計 | 1倍では現実の1秒＝ゲームの1秒。内部積分は30分刻み、端数を保存 |
| 開始季節 | 5月1日（1月1日を0とした120日目）。うるう年のない365日周期 |
| 季節温度 | `T = 17 + 10 sin(2π (yearDay − 80) / 365)` ℃ |
| 活動・発育係数 | `a = clamp((T − 7) / 18, 0.12, 1)` |
| 冬 | `T < 12℃`。産卵と新たな襲撃が止まり、既存の幼虫などはゆっくり成長 |
| 働きアリの発育 | 基準18日（卵）＋22日（幼虫）＋20日（蛹）。実時間は活動係数・栄養で変化 |
| 働きアリの寿命 | 羽化から420日 |
| 母女王の寿命 | 創設から3650〜7300日。初期seedの非負剰余から個体ごとに決定し保存。乱数列を消費せず、再読み込みで変化しない。ユーザー指定の10〜20年を参考にしたゲーム設定で、野外の生存曲線ではない |
| 女王の産卵率 | `min(0.42 + 0.048 W, 32) × a` 個/日。栄養不足・冬には抑制 |
| 子女王の発育 | 基準80日。性・カースト決定や雄の発育は集約モデル |
| 成熟による繁殖 | 創設1095日以上、働きアリ80匹以上、食料25超 |
| 過密による繁殖 | 創設365日以上かつ全個体数が収容目安の155%超。上記の働きアリ・食料条件も必要 |
| 旅立ち | 羽化から12日以上、気温19℃以上、外敵不在。移動・飛行の観察後にクリア |
| 継続後の子女王 | 前回の育成開始から最低365日、冬以外、働きアリ80匹以上、食料25超。観察再開からも最低30日を置き、同じ80日の発育・12日以上の成熟を経る |

「現在の女王アリのその後を観察する」では、旅立った子女王と雄の数、当該世代の育成・飛行状態をリセットします。母女王・働きアリ・通常の幼体・餌・巣・障害物・経過日数・襲撃予定はそのままです。停止倍率で保存されたクリアから続ける場合は1倍で再開します。クリアの選択待ち中は留守中も進みません。続けた後は従来の早送り・実時間の留守中進行が有効になります。母女王の寿命・捕食・飢餓による死亡は継続不可です。寿命の場合は巣を外敵に壊された描画にしません。

過密だけで子女王の生産が必ず決まるという一般的な生態法則ではありません。これはユーザー指定の遊びを表現する独自ルールです。創設直後の大量増殖、女王が直接成虫を生む表現は避け、必ず発育段階を通します。

## 食料と役割

`W` は働きアリ数です。通常は約32%が採餌、18%が掘削、14%が警戒、残りが育児や維持を担います。侵入中は約65%を防衛へ動員し、採餌は12%、掘削は5%になります。役割は集約的に切り替わり、個別の年齢による職業分化はモデル化していません。

食料単位は糖・タンパク源を合算したゲーム単位です。採餌の収入は `0.19 × 採餌数 × a × 移動効率 / 日`、維持費は女王・働きアリ・幼体・子女王ごとの係数を合算します。初期の貯蔵と女王の体内資源で創設期を越えます。食料不足では発育が1/4に落ち、働きアリの死亡と女王の衰弱が進みます。食料の上限は巣の収容目安の2.5倍です。

## 巣と障害物

部屋と通路は連結グラフです。樹形・縦穴・広間の3種類から選び、広さを3段階で設定できます。プレイヤーは部屋の追加、女王室の指定、障害物の設置と削除ができます。初期設計は入口を含む最大20地点、障害物は最大8です。開始後は編集できません。

| 障害物 | 設置区間での働きアリの速度 | 設置区間での外敵の速度 |
|---|---:|---:|
| 小枝 | 64% | 30% |
| 小石 | 44% | 18% |

障害物は指定した通路の位置±11%だけに作用します。逆向きの移動でも同じ物理位置になります。経路探索は通過時間を考慮したDijkstra法です。採餌の効率と防衛への集合時間にも同じ通過時間を使います。別の枝に置いた障害物が女王室までの侵入経路を無条件に遅くすることはありません。

1.3.0では室数・深さの固定上限と規則的な格子候補を撤廃しました。下向きの縦坑、時折分岐する側坑、間隔の異なる横長で凹凸のある部屋を生成します。位置・大きさ・曲がりは決定的な値で保存後も一致し、元の女王室や障害物を移動させません。混雑時は既存室も空間の余裕がある範囲で広がります。増室前に既存室・坑道との干渉を検査します。

CC BY 4.0の実測に基づく構造・3D復元モデルを参考にしました。書誌情報と具体的な対応は [NEST_SOURCES.md](NEST_SOURCES.md) に記録。原モデルを断面表示と独自の生成規則へ置き換えたもので、特定種の寸法・掘削速度を再現したシミュレーションではありません。種ごとの実際の室数・深さと、固定上限を設けないゲーム仕様を区別します。クリアの選択待ち・敗北後は進行が停止し、観察継続を選ぶと増築も再開します。

以下の増室・掘削係数はすべて独自のゲーム設定です。`W` は働きアリ、`P` は女王・幼体を含む全個体数、`B` は掘削する働きアリ、`a` は活動係数、`e` は移動効率です。

| 項目 | 設定 |
|---|---|
| 目標室数 | `max(4 + ceil(max(W−12,0)/32), ceil(P/105))`（固定上限なし） |
| 着工の準備 | `0.025 × B × a × e / 日` を蓄積し、1.5で1室着工 |
| 同時工事数 | 通常1室、働きアリ400匹以上で2室、1200匹以上で3室 |
| 1室の工事進捗 | `min(0.12, 0.0075 × B × a × e / 工事数) / 日` |
| 見える工程 | 0〜55%で接続通路、55〜100%で先端の部屋を掘削 |
| 収容力 | 各部屋の `半径² × 17000 × clamp((進捗−0.55)/0.45,0,1)` の合計 |
| 既存室の拡張 | `P ≥ 0.65 × 収容力` のとき、30分刻みで1室ずつ選び半径を `min(0.0004, Δ日 × B × a × e × 0.000012)` 拡大。各室の目安半径 `0.078 + 0.006 × 巣サイズ + 0.024 × 決定的な個体差` と、隣室・坑道との余白で停止。これは室数上限ではありません |
| 入居 | 完成した育児室へ幼体、貯蔵室へ食料を分散。未完成の通路先端は掘削担当が往復 |

群れと巣の成長を対応させる発想は [Rajendran et al., 2026, Colony demographics shape nest construction in Camponotus fellah ants](https://pubmed.ncbi.nlm.nih.gov/42017334/) を参考にしました。同論文の年齢別の掘削行動や実験係数を再現した実装ではなく、部屋用途の固定ローテーションも観察のための簡略表現です。工事開始・完成時には観察記録が残ります。

## 侵入と戦闘

外敵はハネカクシ、ハサミムシ、オサムシをモチーフにしています。すべての種・個体が定期的に女王室を襲うという主張ではなく、捕食・防衛を観察するためのゲーム内イベントです。

初回は155日目以降、冬を除いて侵入します。撃退後は65〜150日後に次の襲撃が予定されます。種類・HPは経過年数で変化し、働きアリ数に合わせて自動的に同じ難度にする仕組みではありません。防衛数と集合時間からダメージを計算し、外敵が女王室へ到達したら巣の破壊と女王の捕食で終了します。障害物の飛び越しを防ぐため、外敵の移動を空間的に分割しています。

## 観察のための表現

- 生物学的な時間と、画面で読み取れる歩行アニメーションを分けています。早送りでも移動の向き・採餌・育児・掘削・防衛・局所的な障害物は反映しますが、1秒間に数日分の歩数は描きません。
- 大きな群れは最大240匹の働きアリで代表表示します。正確な群れの数は上部の数値です。
- 入巣・襲撃・旅立ちは一時的に最大1時間/秒へ減速し、発生直後の状態を飛ばさないようにします。
- 栄養、湿度、病気、遺伝、フェロモン拡散、3次元の通路、個体同士の衝突は簡略化または省略しています。
- 本作の成長日数は現実の単位で進みますが、厳密な現実の特定種の成長時期を保証するモデルではありません。

## アリの形態・歩行と月別の景観（1.1.0）

描画はCamponotus属を参考にした独自の2D背面モデルです。頭部、大顎、複眼、肘状触角、胸部に接続する6本の関節脚、1節の腹柄、節の境界と微細な毛をもつ腹部を分けています。女王の胸部と腹部を大きくし、入巣時の女王と子女王には前後2対の半透明の翅と翅脈を描きます。女王の脱翅は入巣終了で切り替わる簡略表現です。写真測量や特定種の厳密な形態復元ではありません。

- 形態参考: [California Academy of Sciences / AntWeb, Camponotus japonicus](https://www.antweb.org/images.do?bioregionName=Palearctic&genus=camponotus&rank=species&species=japonicus&subfamily=formicinae)。標本写真はアプリに転載していません。
- 歩行参考: [Clifton et al., 2020, Uneven substrates constrain walking speed in ants through modulation of stride frequency more than stride length](https://pmc.ncbi.nlm.nih.gov/articles/PMC7137955/)。交互三脚歩行と、不整地上で歩調が変化するという知見を参考にしました。本作の係数をこの研究の実測値として扱いません。

左前脚・左後脚・右中脚と、それ以外の3本を交互に動かします。歩行位相は通路上の実際の表示移動距離を積算した `2π × distance / 0.019 + 個体位相差` で、0.019は画面幅を1とした表示用の歩幅です。小枝や小石による減速が足運びにも反映され、静止中に脚だけが歩き続けません。触角は独立して動きますが、一時停止時はすべて止まります。方向転換は最短角で補間します。幼体や休息個体同士の衝突までは再現していません。

背景は保存済みの経過日数から求めた月に対応する12枚を使用します。端末の現在日時・時間帯・タイムゾーンによって季節が勝手に変わることはありません。早送りと留守中の時間経過は同じ暦を使い、一時停止・終了時にはその日の月を保ちます。季節画像は温帯の日本の落葉樹林をモチーフにした生成画で、実際の特定地点の植生・天候の観測データではありません。土中の巣の形と通路は月とは独立しています。

冬ごもり中は代表表示の働きアリを巣内に集め、雪上に採餌列を表示しません。生理計算の低温時の活動係数は既存モデルを維持しています。月別景観は既存の季節温度に対応する見た目の追加で、繁殖・防衛・勝敗の係数は変更していません。


## 外敵の形態（1.2.0）

3種類とも独自制作の2D背面モデルです。6本の脚は胸部につながり、腿節・脛節・跗節と爪、脚の小さな棘、糸状触角の節、複眼、大顎、前胸背板を描きます。ハネカクシは短い上翅と露出した腹節、ハサミムシは褐色の腹部と曲がった尾鉗、オサムシは広い上翅と中央の縫合線・縦の点刻列を持ちます。特定種の寸法を測定した復元や写真素材の貼り付けではありません。

- [University of Minnesota Extension / Rove beetle](https://apps.extension.umn.edu/garden/diagnose/insect/general-curiosity-insects/beetles/small/rove-beetle.html)：細長い体、短い上翅、露出した腹部の参考。
- [UC IPM / Earwigs](https://ipm.ucanr.edu/home-and-landscape/earwigs/)：尾端の対になったはさみの参考。
- [University of Minnesota Extension / Ground beetles](https://extension.umn.edu/garden-and-home/yard-and-garden/yard-and-garden-insects/ground-beetles)：大顎、糸状触角、長い脚、黒褐色の体の参考。

外敵の向きは実際の侵入経路の接線、歩行位相は進んだ距離から計算します。小枝・小石の局所的な減速が脚の動きにも反映されます。各虫24姿勢をキャッシュし、拡大時にも関節や腹節を観察できます。外敵の交互三脚歩行は観察用の共通近似で、種類別の運動計測を再現していません。
